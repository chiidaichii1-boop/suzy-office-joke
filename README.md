Entry for the make.fun bounty [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73).

`main.py` (Python 3 standard library only) writes one original one-line
office joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I finally got a standing desk, so now I can resent my job from a healthier posture.

Run with `python3 main.py`.
